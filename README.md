# Собес.Бот

Телеграм-бот для тренировки вопросов с собеседований. Администратор ведёт банк вопросов с эталонными ответами по категориям (Spark, Airflow и т.д.), пользователи выбирают категорию, отвечают и проверяют ответ через ИИ или сразу смотрят эталон.

## Возможности

**Пользователь** (`/start`)
- Выбор категории. Видны только категории, где есть вопросы с эталоном.
- Вопросы идут по кругу: сначала те, на которые пользователь ещё не отвечал, потом те, что повторял давнее всего.
- Ответ пишется сообщением, затем две кнопки: «🤖 Проверить ИИ» (оценка из 10, что хорошо, чего не хватило, ошибки, уточняющий вопрос, затем эталон) или «📖 Показать эталон».
- `/mystats` — личная статистика.

**Администратор** (`/admin`)
- Добавление категорий и вопросов, эталонный ответ можно задать сразу или позже.
- Импорт списком (сообщением или файлом .txt/.md) в том же формате, что на сайте «Собес.Тренер».
- Просмотр вопросов по категориям, добавление и изменение эталонных ответов, удаление вопросов и категорий (с подтверждением).
- Статистика: пользователи (всего, новые, активные), ответы, проверки ИИ, просмотры эталона, средняя оценка, разбивка по категориям, самые активные пользователи.

### Почему доступ к админке по Telegram ID, а не по паролю

Панель открывается только пользователям, чьи Telegram ID перечислены в `ADMIN_IDS`. ID отправителя подставляет сам Telegram, подделать его нельзя. Пароль же можно подобрать, подсмотреть или переслать, а ещё он остаётся в истории чата. Обычному пользователю на `/admin` бот отвечает «Нет доступа», а кнопки админки (даже пересланные) у него не срабатывают.

### Проверка ответов

Как и на сайте, используется **Groq** (бесплатно) с моделью `openai/gpt-oss-120b` и тем же промптом интервьюера. Если ключ не задан или Groq недоступен, бот ставит упрощённую оценку без ИИ по совпадению ключевых понятий с эталоном. Можно подключить любой OpenAI-совместимый API, в том числе локальную Ollama (см. `.env.example`).

## Запуск локально

### 1. Подготовка (один раз)

1. Установите Python 3.11 или новее: https://www.python.org/downloads/ (на Windows отметьте «Add python.exe to PATH»).
2. Скачайте проект и перейдите в папку:
   ```bash
   git clone https://github.com/daniilivanovp-droid/sobes_bot.git
   cd sobes_bot
   ```
3. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Создайте файл настроек:
   ```bash
   cp .env.example .env             # Windows: copy .env.example .env
   ```

### 2. Создайте бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя и username.
2. Скопируйте токен (вида `123456:ABC...`) в `.env`: `BOT_TOKEN=123456:ABC...`

### 3. Подключите Groq для проверки ответов

1. Зарегистрируйтесь на https://console.groq.com (карта не нужна).
2. На https://console.groq.com/keys нажмите **Create API Key** и вставьте ключ в `.env`: `GROQ_API_KEY=gsk_...`

Бесплатный лимит Groq: около 30 проверок в минуту и 1000 в день.

### 4. Запустите и назначьте себя администратором

```bash
python -m bot
```

1. Откройте своего бота в Telegram и отправьте `/id`, бот пришлёт ваш Telegram ID.
2. Остановите бота (Ctrl+C), впишите ID в `.env`: `ADMIN_IDS=123456789` (несколько через запятую).
3. Снова `python -m bot`, отправьте `/admin`.

Бот работает, пока открыт терминал. База хранится в `data/bot.db`.

## Формат импорта

```
# Spark
Что такое RDD?
Неизменяемая распределённая коллекция...
---
Что такое shuffle?
Перераспределение данных между партициями...
---
# Airflow
Что такое DAG?
Граф задач...
```

Вопросы разделяются строкой `---`. Первая строка блока — вопрос, остальное — эталонный ответ (можно оставить пустым и добавить позже через «Вопросы и ответы»). `# Категория` задаёт категорию для этого и следующих вопросов, без неё вопросы попадают в «Общее». Сообщение в Telegram ограничено 4096 символами, большой банк удобнее отправить файлом.

## Разработка

Проект сделан по TDD: тесты лежат в `tests/` и прогоняют сценарии пользователя и администратора через настоящий диспетчер aiogram с подменённым Telegram API, а Groq подменяется заглушкой.

```bash
pip install -r requirements-dev.txt
pytest
```

Структура:
- `bot/storage.py` — SQLite: категории, вопросы, пользователи, попытки, статистика.
- `bot/grader.py`, `bot/llm.py` — проверка ответа ИИ (Groq / OpenAI-совместимый API) и запасная оценка без ИИ.
- `bot/parsing.py` — разбор импорта.
- `bot/handlers/` — панели пользователя (`user.py`) и администратора (`admin.py`), общие команды (`common.py`).
- `bot/__main__.py` — запуск.
